# Live Demo Checklist

## Before The Event

- [ ] Use Node 20.
- [ ] Run `cd frontend && npm ci`.
- [ ] Run `cd frontend && npm run build`.
- [ ] Run `cd frontend && npm test -- --watch=false --browsers=ChromeHeadless`.
- [ ] Start frontend dev server.
- [ ] Open `/workshop`.
- [ ] Confirm backend containers are not required.

## Golden Path Check

- [ ] Tree renders.
- [ ] `Sessao 01 - O arquivo vivo` opens.
- [ ] `/` menu opens.
- [ ] Callout block inserts.
- [ ] `@Augustus Frostborne` creates a relation.
- [ ] Timeline updates.
- [ ] Backlink appears on Augustus page.
- [ ] Graph edge appears.

## Presenter Safety

- [ ] Keep `/workshop` bookmarked.
- [ ] Keep a built production preview available if dev server fails.
- [ ] Do not navigate to `/campaigns`, `/dice`, or authenticated pages.
