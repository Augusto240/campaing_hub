# Campaign Hub Constitution

Canonical governance lives in `.specify/memory/constitution.md`.

The workshop recovery pass is governed by these non-negotiables:

- Angular 17 standalone components only for `/workshop`.
- Frontend mock data only; no backend, auth, database, Redis, Prisma, or Socket.IO.
- Block composition and semantic memory are the product surface.
- Legacy VTT/RPG operational systems are frozen and hidden from the demo.
- Clean, stable UX beats feature count.

See `.specify/memory/constitution.md` for the full versioned constitution.
